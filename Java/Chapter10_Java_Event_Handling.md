# 📅 2026-07-12 (이벤트 기반 프로그래밍)

## ✅ 배운 내용

### 1. 이벤트 기반 프로그래밍

이벤트 기반 프로그래밍(Event-Driven Programming)은 **이벤트(Event)의 발생에 따라 프로그램의 실행 흐름이 결정되는 프로그래밍 방식**이다.

이벤트는 다음과 같은 다양한 상황에서 발생할 수 있다.

- 키보드 입력
- 마우스 클릭 및 드래그
- 센서 등 외부 장치의 입력
- 네트워크를 통한 데이터 수신
- 다른 스레드나 프로그램으로부터의 메시지 수신

일반적인 프로그램은 개발자가 작성한 순서대로 실행되지만, 이벤트 기반 프로그램은 **이벤트가 발생할 때마다 해당 이벤트를 처리하는 이벤트 리스너(Event Listener)가 실행**된다.  
따라서 어떤 코드가 언제 실행될지는 이벤트의 발생 여부에 따라 결정된다.  
GUI 응용프로그램은 대부분 이벤트 기반 프로그래밍 방식으로 작성되며, 자바는 AWT와 Swing을 통해 이벤트 기반 GUI 프로그래밍을 지원한다.

### 2. 자바의 이벤트 기반 GUI 응용프로그램 구조

이벤트를 처리하는 프로그램은 **이벤트 리스너(Event Listener)** 이며, 반드시 컴포넌트에 등록되어 있어야 동작한다.

예를 들어 사용자가 버튼을 클릭하면 다음과 같은 과정으로 이벤트가 처리된다.

1. 사용자가 버튼을 클릭한다.
2. 버튼 클릭 이벤트가 운영체제를 거쳐 JVM(Java Virtual Machine)에 전달된다.
3. JVM은 이벤트 정보를 **이벤트 큐(Event Queue)** 에 저장한다.
4. 이벤트 분배 스레드(Event Dispatch Thread)가 이벤트 큐에서 이벤트를 가져와 **이벤트 객체(Event Object)** 를 생성한다.
5. 이벤트를 발생시킨 컴포넌트(이벤트 소스)에 등록된 **이벤트 리스너**를 찾아 호출한다.
6. 이벤트 처리가 끝나면 이벤트 분배 스레드는 다음 이벤트를 기다린다.

#### 이벤트 소스

이벤트를 발생시킨 GUI 컴포넌트이다.  
예를 들어 버튼을 클릭했다면 버튼(`JButton`)이 이벤트 소스가 된다.

#### 이벤트 객체

발생한 이벤트에 대한 정보를 저장하는 객체이다.

이벤트 종류에 따라 다음과 같은 정보를 포함한다.

- 이벤트 종류
- 이벤트 소스
- 마우스 좌표
- 마우스 버튼 종류
- 입력된 키 값 등

#### 이벤트 리스너(Event Listener)

이벤트가 발생했을 때 실행되는 코드이다.  
이벤트 리스너는 반드시 컴포넌트에 등록되어 있어야 이벤트를 처리할 수 있다.

#### 이벤트 분배 스레드(Event Dispatch Thread)

이벤트 기반 프로그래밍의 핵심이 되는 스레드이다.  
이벤트 큐에서 이벤트를 가져와 이벤트 객체를 생성하고, 해당 이벤트를 처리할 이벤트 리스너를 호출하는 역할을 수행한다.

# 📅 2026-07-13 (이벤트 객체)

## ✅ 배운 내용

### 1. 이벤트 객체란?

이벤트 객체(Event Object)는 **현재 발생한 이벤트에 대한 정보를 담고 있는 객체**이며, 이벤트가 발생하면 이벤트 리스너에게 전달된다.  
이벤트 객체의 종류는 다양하며, 모든 이벤트 객체는 `java.util.EventObject` 클래스를 상속받는다.  
이벤트 관련 클래스들은 `java.awt.event`와 `javax.swing.event` 패키지에 포함되어 있다.

이벤트를 처리하기 위해서는 다음과 같은 import 문을 사용한다.

```java
import java.awt.event.*;
import javax.swing.event.*;
```

### 2. 이벤트 객체 정보

이벤트 객체는 발생한 이벤트에 따라 조금씩 다른 정보를 저장하지만, 일반적으로 다음과 같은 정보를 포함한다.

- 이벤트 종류
- 이벤트 소스(Event Source)
- 화면에서 이벤트가 발생한 마우스 좌표
- 컴포넌트 내부에서 이벤트가 발생한 마우스 좌표
- 버튼이나 메뉴 아이템의 문자열
- 클릭된 마우스 버튼 번호
- 마우스 클릭 횟수
- 눌린 키의 코드 값과 문자 값
- 체크박스나 라디오 버튼의 선택 상태

이러한 정보는 이벤트 객체가 제공하는 메소드를 통해 얻을 수 있다.

#### Object getSource()

`getSource()` 메소드는 현재 이벤트를 발생시킨 **이벤트 소스(Event Source)** 를 반환한다.
반환 타입은 `Object`이므로 실제 컴포넌트 타입으로 형변환하여 사용한다.

예를 들어 버튼에서 이벤트가 발생했다면 다음과 같이 사용할 수 있다.

```java
JButton button = (JButton) event.getSource();
```

### 3. 이벤트 객체와 이벤트 소스

각 이벤트 객체는 특정 컴포넌트(이벤트 소스)에서 발생하며, 발생 가능한 이벤트도 서로 다르다.

| 이벤트 객체          | 이벤트 소스                                      | 이벤트 발생 상황                           |
| -------------------- | ------------------------------------------------ | ------------------------------------------ |
| `ActionEvent`        | `JButton`, `JMenuItem`, `JTextField`             | 버튼 클릭, 메뉴 선택, 텍스트 입력 후 Enter |
| `ItemEvent`          | `JCheckBox`, `JRadioButton`, `JCheckBoxMenuItem` | 선택 또는 해제 상태 변경                   |
| `ListSelectionEvent` | `JList`                                          | 리스트의 선택 항목 변경                    |
| `KeyEvent`           | `Component`                                      | 키 입력 또는 키를 뗄 때                    |
| `MouseEvent`         | `Component`                                      | 마우스 클릭, 이동, 드래그, 진입, 종료 등   |
| `FocusEvent`         | `Component`                                      | 포커스를 얻거나 잃을 때                    |
| `WindowEvent`        | `Window`                                         | 창 열기, 닫기, 활성화, 비활성화 등         |
| `AdjustmentEvent`    | `JScrollBar`                                     | 스크롤바를 움직일 때                       |
| `ComponentEvent`     | `Component`                                      | 컴포넌트의 이동, 크기 변경, 표시 여부 변경 |
| `ContainerEvent`     | `Container`                                      | 컴포넌트가 추가되거나 삭제될 때            |
