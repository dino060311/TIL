# Chapter 04. 클래스와 객체

## 📅 2026-05-02 (객체 지향과 자바)

### ✅ 배운 내용

**객체의 본질**

- 정의: 실세계의 모든 존재를 객체로 보며, 각 객체는 자신만의 고유한 상태(특성)와 행동을 가짐.
- 상호작용: 객체들은 서로 고립된 것이 아니라, 상대 객체에게 특정 행동을 요청하거나 정보를 주고받는 방식으로 상호 작용하면서 존재함.

**캡슐화 (Encapsulation)**

- 객체를 캡슐로 싸서 내부를 보호하고 볼 수 없게 하는 것으로 객체의 가장 본질적인 특징임.
- 자바에서의 구현: 클래스(Class)라는 캡슐을 사용함.

**상속 (Inheritance)**

- 개념: 슈퍼 클래스(부모)의 특성을 서브 클래스(자식)가 물려받는 것입니다.
- 슈퍼 클래스의 필드와 메소드를 물려받아 코드를 재사용함으로써, 코드 작성에 드는 시간과 비용을 줄임.

**다형성 (Polymorphism)**

- 개념: 같은 이름의 메소드가 클래스 혹은 객체에 따라 다르게 동작하도록 구현된 것을 말함.
- 같은 이름의 메소드가 클래스에 따라 다르게 동작하는 오버라이딩(Overriding) 등이 있습니다.

**객체 지향 언어의 목적**

- 소프트웨어의 재사용성 및 생산성 향상: 이미 만들어진 코드를 재사용하기 쉽고, 복잡한 시스템을 관리하기 용이하게 함으로써 개발 속도를 높임.
- 유지보수의 용이성: 수정이 필요한 부분만 고칠 수 있어 대규모 프로젝트 관리에 유리합니다.

**절차 지향 프로그래밍과 객체 지향 프로그래밍**

(1) 절차 지향 프로그래밍

- 중점: 실행하고자 하는 절차(순서)와 함수 중심임.
- 특징: 데이터를 처리하는 방법(알고리즘)을 순차적으로 나열하며, 데이터와 함수가 분리되어 있음.
- 단점: 프로그램 규모가 커지면 구조가 복잡해져 유지보수와 수정이 어려움.

(2) 객체 지향 프로그래밍

- 중점: 실세계의 개체를 모델링한 객체 중심임.
- 특징: 데이터(필드)와 그 데이터를 다루는 기능(메소드)을 하나의 객체로 묶어서 관리함.
- 장점: 코드의 재사용성이 높고 유지보수가 쉬우며, 대형 프로젝트에 적합함.

## 📅 2026-05-03 (자바 클래스 만들기)

### ✅ 배운 내용

**클래스와 객체**

- 클래스: 객체를 만들어 내기 위한 설계도 혹은 틀.
- 객체: 클래스 모양 그대로 생성된 실체. 클래스의 인스턴스라고도 부름.  
  (예: 붕어빵 틀은 자바 클래스, 붕어빵은 자바 객체)
- 특징: 하나의 클래스로부터 수많은 객체를 생성할 수 있으며, 모두 동일한 속성을 가지지만 자신만의 고유한 값을 가짐.

**클래스 구성 요소**

- 자바 클래스는 `class` 키워드를 사용하여 선언하며, 멤버는 필드와 메소드로 구성됨.
- 필드: 객체의 상태 값을 저장하는 멤버 변수
- 메소드: 객체의 행동(기능)을 구현하는 함수
- 접근 지정자(public): 선언된 클래스나 멤버를 외부 클래스에서 자유롭게 접근할 수 있도록 허용함.
- 생성자: 클래스의 이름과 동일한 메소드를 생성자라하며, 객체가 생성될 때 자동으로 호출되는 특별한 메소드임.

2. 필드와 메소드

- 필드(Field): 객체의 상태 값을 저장하는 멤버 변수.
- 메소드(Method): 객체의 행동(기능)을 구현하는 함수.

**객체 생성 및 접근**

1. 레퍼런스 변수 선언: 객체를 생성하기 전, 객체를 가리킬 레퍼런스 변수를 먼저 선언함.

```java
Circle pizza; // 레퍼런스 변수 선언 (객체가 생성된 것은 아님)
```

2. new 연산자와 객체 생성: 자바에서는 반드시 new 연산자를 사용하여 객체를 생성함.

```java
pizza = new Circle(); // 객체 생성 및 레퍼런스 대입
```

3. 객체 멤버 접근: 생성된 객체의 필드나 메소드에 접근할 때는 `점(.) 연산자`를 사용함.

- `pizza.radius = 10;` (필드 접근)
- `pizza.getArea();` (메소드 호출)
